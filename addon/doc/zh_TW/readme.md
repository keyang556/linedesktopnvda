# LINE 電腦版 NVDA 輔助工具

> **建議安裝版本：Windows 版 LINE 26.6.0.4004 以上**
>
> 從 26.6.0.4004 開始，LINE 本身就會向 NVDA 提供聊天清單、訊息（包含回覆引用的原始訊息、時間與已讀人數）、分頁、按鈕與編輯欄位。按 Tab 或方向鍵時，NVDA 會直接讀出這些內容，因此本附加元件不再使用 OCR 或剪貼簿來讀取訊息。使用此版本附加元件前請先更新 LINE：在較舊的 LINE 版本中，聊天清單與訊息可能完全無法讀出。
>
> 若您同時安裝了 [LINE MR for Windows](https://github.com/Peetchy/line-mr-for-win)，請勿與本附加元件同時啟用；兩者都提供 LINE 的 NVDA 應用程式模組。

## 概述

此附加元件增強了 NVDA 螢幕閱讀器對 Windows 上 LINE 電腦版（Qt6 版本）的支援。LINE 的介面、訊息、選單與對話框由 NVDA 直接讀取；本附加元件在此之上提供通話、訊息快速鍵、聊天紀錄閱讀器與可選的 AI 圖片描述，並只在 LINE 尚未提供資訊的地方使用 OCR（文字辨識）與座標自動化技術。

> [!IMPORTANT]
> 通話視窗仍使用 OCR，因此辨識結果不一定完全準確。閱讀訊息、訊息快速鍵與讀取聊天室名稱不使用 OCR（只有在 LINE 介面語言不是繁體中文時，聊天室名稱才會改用 OCR）。

## 功能特色

* **語音與視訊通話**：從好友分頁發起通話。
* **來電處理**：接聽、拒絕來電，以及查看來電者資訊。
* **OCR 輔助**：只用於 LINE 尚未提供文字的地方，例如通話視窗。聊天室名稱直接取自 LINE 的聊天室標題，只有在 LINE 介面語言不是繁體中文時才改用 OCR。
* **除錯工具**：提供快速鍵以檢查 UI 結構，便於排除故障。
* **訊息閱讀器**：匯出目前聊天室內容，並在簡潔可讀的閱讀視窗中逐則瀏覽。
* **AI 圖片描述**：使用可設定的 AI 服務描述目前焦點所在的圖片或貼圖訊息，並可在可讀對話視窗中繼續追問。
* **狀態回饋**：通話中的麥克風與相機開關後會播報狀態，訊息確實送出時也會播放短音效。

## 使用技巧與提醒

* **建立紀錄**：在使用此版本傳送訊息給某人之前，建議先使用手機或 Chrome 網頁版傳送一次訊息。有聊天紀錄後，附加元件更容易定位 UI 元素。
* **傳送訊息**：
    1. 搜尋好友名稱。盡可能輸入準確的關鍵字，使搜尋結果只有一個好友，以避免錯誤。
    2. 在聊天室上按 `Enter` 開啟，焦點會移到訊息清單；再按 `Tab` 移到訊息輸入欄。
    3. 輸入訊息後按 `Enter` 傳送。
* **撥打電話**：
    目前無法透過此附加元件從聊天分頁直接撥打電話。請依以下步驟操作：
    1. 按 `Control+1` 切換到好友分頁。
    2. 搜尋好友名稱，選取好友並開啟聊天室。
    3. 按 `NVDA+Windows+C` 撥打語音通話，或按 `NVDA+Windows+V` 撥打視訊通話。
* **描述圖片**：
    1. 將焦點移到圖片或貼圖訊息。
    2. 按 `NVDA+Windows+I`。
    3. 在「圖片描述」對話視窗閱讀結果；若要針對同一張圖片追問，輸入問題後按 `Ctrl+Enter` 送出。
* **事前檢查**：傳送訊息或撥打電話之前，請務必先檢查聊天紀錄，確認對象是否正確。

### 音效提示

* **訊息送出音效**：在訊息輸入欄按 `Enter` 且 LINE 確實送出訊息後，附加元件會播放短音效；若 `Enter` 只是用來確認輸入法組字，則不會播放。

## 訊息閱讀與複製

* **閱讀訊息**：使用 LINE 26.6.0.4004 以上版本時，在訊息列表中用方向鍵移動，NVDA 會直接讀出每則訊息，包含傳送者、回覆所引用的原始訊息、時間與已讀人數。附加元件不再對訊息按右鍵或使用 OCR 來閱讀，也不會動到您的剪貼簿。
* **複製訊息**：在訊息列表中按下 `Control+C`，附加元件會從 LINE 本身的訊息右鍵選單選擇「複製」。若選單中沒有「複製」，附加元件會直接告知。

## 訊息閱讀器與右鍵選單

* **訊息閱讀器 (`NVDA+Windows+J`)**：附加元件會開啟聊天室的「更多選項」選單，自動選擇「儲存聊天」，解析匯出的文字，並開啟可讀的訊息閱讀器視窗。
* **閱讀器操作**：在訊息閱讀器中可使用 `UpArrow` / `DownArrow` 逐項移動，`PageUp` / `PageDown` 每次快速跳轉 10 個項目，`Ctrl+Home` / `Ctrl+End` 跳至第一／最後一項，按 `Escape` 關閉視窗。日期分隔線會保留，並播報目前進度。
* **訊息右鍵選單 (`Applications` / `Shift+F10`)**：在訊息列表中按這兩個鍵，會開啟 LINE 本身的訊息右鍵選單（回覆、複製、分享、收回、翻譯、轉為文字等），由 NVDA 直接讀出：用 `上方向鍵` / `下方向鍵` 移動、`Enter` 執行、`Escape` 關閉。附加元件不再以 OCR 虛擬選單取代它。
* **訊息快速鍵**：`NVDA+Windows+R`（回覆）、`NVDA+Windows+K`（另存新檔）、`NVDA+Windows+Delete`（收回）與 `Control+C`（複製）會開啟同一個選單並替您選擇項目，因此只在 LINE 的選單有該項目時才有作用。
* **收回確認**：選擇收回後（從選單或按 `NVDA+Windows+Delete`），LINE 會顯示自己的確認對話框，由 NVDA 直接讀出：按 `Tab` 聽取提示並移到「收回」按鈕，再按 `空白鍵` 或 `Enter`。附加元件不再另外開啟確認對話框。
* **圖片轉文字提示**：第一次使用「轉為文字」時的照片上傳提示，同樣交給 LINE 本身的對話框處理。

## AI 圖片描述

* **快速鍵 (`NVDA+Windows+I`)**：擷取目前焦點所在的圖片或貼圖訊息，送到已設定的圖片描述服務。
* **對話視窗**：第一次描述結果會在可調整大小的對話視窗中顯示，內容區為唯讀。可在輸入欄針對同一張圖片提出後續問題，按 `Ctrl+Enter` 送出。
* **設定**：開啟「NVDA 功能表 -> 偏好 -> 設定 -> LINE Desktop」，可選擇圖片描述服務、API Key、模型與提示詞。API Key 或提示詞留空時會使用預設設定。
* **隱私提醒**：圖片描述會將擷取到的訊息圖片傳送到所選的雲端 AI 服務。第一次使用某項服務時，會出現載明該服務名稱的同意對話框；未同意前不會上傳任何內容。無論使用附加元件內建的共用金鑰或自己的 API Key 都會詢問，因為要確認的是「哪一家公司會收到您的截圖」。同意狀態會依服務分別記錄，更換服務後會再次詢問。請依圖片內容選擇合適的服務與提示詞。
