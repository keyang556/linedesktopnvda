# LINE デスクトップ版 NVDA アドオン

> **推奨する LINE のバージョン：Windows 版 LINE 26.6.0.4004 以降**
>
> 26.6.0.4004 から、LINE 自体がチャットリスト、メッセージ（返信の引用元、時刻、既読数を含む）、タブ、ボタン、入力欄を NVDA に提供するようになりました。Tab キーや矢印キーを押すと NVDA がそのまま読み上げるため、本アドオンは OCR やクリップボードでメッセージを読み取らなくなりました。このバージョンのアドオンを使う前に LINE を更新してください。古いバージョンの LINE では、チャットリストやメッセージがまったく読み上げられない場合があります。
>
> [LINE MR for Windows](https://github.com/Peetchy/line-mr-for-win) も使用している場合は、本アドオンと同時に有効化しないでください。どちらも LINE 用の NVDA アプリモジュールを提供します。

## 概要

このアドオンは、Windows 版 LINE デスクトップアプリ（Qt6 バージョン）の NVDA スクリーンリーダーサポートを強化します。LINE の画面、メッセージ、メニュー、ダイアログは NVDA が直接読み上げ、本アドオンはその上に通話、メッセージ用ショートカット、チャット履歴リーダー、任意の AI 画像説明を提供します。OCR（文字認識）と座標ベースの自動化は、LINE がまだ情報を提供していない部分にだけ使用します。

> [!IMPORTANT]
> 一部の操作（通話ウィンドウとチャットルーム名の読み上げ）は引き続き OCR を使用するため、認識結果が完全に正確ではない場合があります。メッセージの読み上げとメッセージ用ショートカットには OCR を使用しません。

## 特徴

* **音声・ビデオ通話**：友だちタブから通話を開始します。
* **着信対応**：着信の応答、拒否、発信者情報の確認が可能です。
* **OCR 補助**：通話ウィンドウやチャットルーム名など、LINE がまだテキストを提供していない部分にだけ使用します。
* **デバッグツール**：UI 構造を確認し、トラブルシューティングに役立つショートカットを提供します。
* **メッセージリーダー**：現在のチャットをエクスポートし、シンプルで読みやすい閲覧ダイアログで確認できます。
* **AI 画像説明**：設定した AI サービスでフォーカス中の画像またはスタンプメッセージを説明し、アクセシブルなダイアログで追加質問できます。
* **状態フィードバック**：通話中のマイク・カメラ切り替えを読み上げ、メッセージ送信成功時には短い音を鳴らします。

## 使用上のヒントと注意点

* **接続の確立**：このアドオンを使用して初めてメッセージを送信する前に、一度スマートフォンまたは Chrome 版でメッセージを送信しておくことをお勧めします。チャット履歴があることで、アドオンが UI 要素を特定しやすくなります。
* **メッセージの送信**：
    1. 友達の名前を検索します。間違いを避けるため、検索結果が 1 つになるようなキーワードを使用してください。
    2. チャットで `Enter` を押して開くと、フォーカスがメッセージリストに移ります。`Tab` を押してメッセージ入力欄に移動します。
    3. メッセージを入力して `Enter` キーを押すと送信されます。
* **電話をかける**：
    現在、このアドオンを使用してチャットタブから直接電話をかけることはできません。以下の手順に従ってください：
    1. `Control+1` を押して友だちタブに切り替えます。
    2. 友だちの名前を検索し、選択してチャットルームを開きます。
    3. `NVDA+Windows+C` で音声通話、または `NVDA+Windows+V` でビデオ通話を開始します。
* **画像を説明する**：
    1. 画像またはスタンプメッセージにフォーカスを移動します。
    2. `NVDA+Windows+I` を押します。
    3. 「画像説明」ダイアログで結果を読みます。同じ画像について追加質問する場合は、質問を入力して `Ctrl+Enter` を押します。
* **確認**：メッセージの送信や通話を行う前に、必ずチャット履歴を確認し、送信先が正しいか確かめてください。

### サウンドエフェクト

* **送信音**：メッセージ入力欄で `Enter` を押して実際に送信が完了したときだけ、短い音を再生します。IME の変換確定だけだった場合は音は鳴りません。

## メッセージの読み上げとコピー

* **メッセージの読み上げ**：LINE 26.6.0.4004 以降では、メッセージリスト内を矢印キーで移動すると、NVDA が各メッセージを直接読み上げます。送信者、返信の引用元、時刻、既読数も含まれます。アドオンはメッセージを右クリックしたり OCR で読み取ったりしなくなり、クリップボードにも触れません。
* **メッセージのコピー**：メッセージリスト内で `Control+C` を押すと、アドオンが LINE 自体のコンテキストメニューから「コピー」を選びます。メニューに「コピー」がない場合は、その旨をお知らせします。

## メッセージリーダーとコンテキストメニュー

* **メッセージリーダー (`NVDA+Windows+J`)**：チャットルームの「その他のオプション」メニューを開き、「チャットを保存」を自動選択して、書き出したテキストを解析し、アクセシブルなリーダーダイアログを開きます。
* **リーダーの操作**：メッセージリーダーでは `UpArrow` / `DownArrow` で1項目ずつ移動し、`PageUp` / `PageDown` で10項目ずつ移動し、`Ctrl+Home` / `Ctrl+End` で最初／最後の項目へ移動し、`Escape` で閉じます。日付の区切りは保持され、現在位置も案内されます。
* **メッセージのコンテキストメニュー (`Applications` / `Shift+F10`)**：メッセージリストでこれらのキーを押すと、LINE 自体のコンテキストメニュー（返信、コピー、共有、取り消し、翻訳、「テキストに変換」など）が開き、NVDA が直接読み上げます。`上矢印` / `下矢印` で移動、`Enter` で実行、`Escape` で閉じます。アドオンは OCR による仮想メニューで置き換えなくなりました。
* **メッセージ用ショートカット**：`NVDA+Windows+R`（返信）、`NVDA+Windows+K`（名前を付けて保存）、`NVDA+Windows+Delete`（取り消し）、`Control+C`（コピー）は同じメニューを開いて項目を選ぶため、LINE のメニューにその項目がある場合にだけ動作します。
* **取り消しの確認**：取り消しを選ぶと（メニューから、または `NVDA+Windows+Delete` で）、LINE 自体の確認ダイアログが表示され、NVDA が直接読み上げます。`Tab` で確認文を聞いて「取り消し」ボタンに移動し、`Space` または `Enter` を押してください。アドオンは独自の確認ダイアログを開かなくなりました。
* **画像のテキスト化の通知**：初回の「テキストに変換」で表示される写真アップロード通知も、LINE 自体のダイアログに任せます。

## AI 画像説明

* **ショートカット (`NVDA+Windows+I`)**：フォーカス中の画像またはスタンプメッセージをキャプチャし、設定した画像説明サービスに送信します。
* **ダイアログ**：最初の説明はサイズ変更可能なダイアログに表示され、会話履歴は読み取り専用です。同じ画像について質問を入力し、`Ctrl+Enter` で追加質問を送信できます。
* **設定**：「NVDA メニュー -> 設定 -> LINE Desktop」を開くと、画像説明サービス、API Key、モデル、プロンプトを選択できます。API Key またはプロンプトを空欄にすると既定の設定を使用します。
* **プライバシー上の注意**：画像説明では、キャプチャしたメッセージ画像を選択したクラウド AI サービスへ送信します。各サービスを初めて使用するときに、そのサービス名を明記した同意ダイアログが表示され、同意するまで何もアップロードされません。アドオン内蔵の共有キーでも自分の API Key でも確認します。確認しているのは「どの企業にスクリーンショットが送信されるか」だからです。同意はサービスごとに記憶されるため、別のサービスに変更すると再度確認します。説明する内容に適したサービスとプロンプトを選んでください。

## キーボードショートカット

> [!NOTE]
> 「カテゴリ」列の「アドオン」はこのアドオンが提供するショートカット、「LINE」は LINE デスクトップ版内蔵のショートカットを示します。

> [!TIP]
> これらのショートカットは「NVDA メニュー → 設定 → 入力ジェスチャー」でカスタマイズできます。

### 通話・着信

| ショートカット | カテゴリ | 操作 |
|---|---|---|
| **NVDA+Windows+C** | アドオン | 音声通話を開始 |
| **NVDA+Windows+V** | アドオン | ビデオ通話を開始 |
| **NVDA+Windows+A** | アドオン | 着信に応答 |
| **NVDA+Windows+D** | アドオン | 着信を拒否 |
| **NVDA+Windows+S** | アドオン | 発信者を確認 |
| **NVDA+Windows+F** | アドオン | 通話ウィンドウにフォーカス |
| **Ctrl+Shift+A** | LINE | マイクのオン／オフ。通話中はアドオンが新しい状態を読み上げます |
| **Ctrl+Shift+V** | LINE | カメラのオン／オフ。通話中はアドオンが新しい状態を読み上げます |

### メッセージ操作

| ショートカット | カテゴリ | 操作 |
|---|---|---|
| **Control+C** | アドオン | 現在のメッセージをコピー（メッセージリスト内で使用、編集欄では通常のコピー） |
| **NVDA+Windows+R** | アドオン | 現在のメッセージに返信 |
| **NVDA+Windows+Delete** | アドオン | 現在のメッセージを取り消し（送信取り消し）。その後 LINE 自体の確認ダイアログが表示されます |
| **NVDA+Windows+T** | アドオン | 現在のチャットルーム名を読み上げ |
| **NVDA+Windows+K** | アドオン | 名前を付けて保存ダイアログを開く（ファイルはアップロード後7日間のみダウンロード可能） |
| **NVDA+Windows+I** | アドオン | 設定した AI サービスで現在の画像またはスタンプメッセージを説明 |
| **Applications / Shift+F10** | LINE | 現在のメッセージの LINE コンテキストメニューを開く |
