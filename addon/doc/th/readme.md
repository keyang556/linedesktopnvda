# ส่วนเสริม NVDA สำหรับเพิ่มประสิทธิภาพการเข้าถึง LINE Desktop

> **เวอร์ชัน LINE ที่แนะนำ: LINE สำหรับ Windows 26.6.0.4004 หรือใหม่กว่า**
>
> ตั้งแต่เวอร์ชัน 26.6.0.4004 เป็นต้นไป LINE ส่งข้อมูลรายการแชท ข้อความ (รวมถึงข้อความต้นฉบับที่ถูกตอบกลับ เวลา และจำนวนผู้อ่าน) แท็บ ปุ่ม และช่องกรอกข้อความให้ NVDA ได้เอง เมื่อกด Tab หรือปุ่มลูกศร NVDA จะอ่านได้โดยตรง ส่วนเสริมนี้จึงไม่ใช้ OCR หรือคลิปบอร์ดในการอ่านข้อความอีกต่อไป โปรดอัปเดต LINE ก่อนใช้ส่วนเสริมเวอร์ชันนี้ เพราะใน LINE เวอร์ชันเก่า รายการแชทและข้อความอาจอ่านไม่ได้เลย
>
> หากคุณใช้ [LINE MR for Windows](https://github.com/Peetchy/line-mr-for-win) ด้วย อย่าเปิดใช้งานพร้อมกับส่วนเสริมนี้ เนื่องจากทั้งสองมีโมดูล NVDA สำหรับ LINE

## ภาพรวม (Overview)

ส่วนเสริม (Add-on) นี้ช่วยเพิ่มประสิทธิภาพการทำงานของโปรแกรมอ่านหน้าจอ NVDA สำหรับแอปพลิเคชัน LINE บน Windows (เวอร์ชัน Qt6) NVDA อ่านหน้าจอ ข้อความ เมนู และกล่องโต้ตอบของ LINE ได้โดยตรง ส่วนเสริมนี้เพิ่มการโทร คีย์ลัดสำหรับข้อความ โปรแกรมอ่านประวัติแชท และการอธิบายรูปภาพด้วย AI แบบเลือกใช้ได้ โดยใช้ OCR และการสั่งการแบบระบุพิกัดอัตโนมัติเฉพาะส่วนที่ LINE ยังไม่ส่งข้อมูลให้เท่านั้น

> [!IMPORTANT]
> **ข้อควรทราบ**: หน้าต่างการโทรยังใช้ OCR อยู่ ผลลัพธ์จึงอาจไม่ถูกต้องแม่นยำ 100% การอ่านข้อความและคีย์ลัดสำหรับข้อความไม่ใช้ OCR ชื่อห้องแชทอ่านจาก LINE โดยตรง และจะใช้ OCR เฉพาะเมื่อระบุปุ่มชื่อห้องแชทไม่ได้ (เช่น เมื่อภาษาของ LINE ไม่ใช่ภาษาจีนตัวเต็ม)

## คุณสมบัติเด่น (Features)

* **การโทรด้วยเสียงและวิดีโอ**: เริ่มการโทรจากแท็บเพื่อน
* **การจัดการสายเรียกเข้า**: รับสาย ปฏิเสธสาย หรือตรวจสอบข้อมูลผู้โทร
* **OCR ช่วยเสริม**: ใช้เฉพาะส่วนที่ LINE ยังไม่ส่งข้อความให้ เช่น หน้าต่างการโทร ชื่อห้องแชทอ่านจากส่วนหัวของแชทใน LINE โดยตรง และใช้ OCR เฉพาะเมื่อระบุปุ่มชื่อห้องแชทไม่ได้ เช่น ในภาษาอื่น
* **เครื่องมือช่วยเหลือ (Debug Tools)**: มีคีย์ลัดสำหรับตรวจสอบโครงสร้าง UI เพื่อใช้ในการแก้ไขปัญหา
* **โปรแกรมอ่านข้อความแชท**: ส่งออกห้องแชทปัจจุบันและเปิดอ่านในหน้าต่างอ่านที่เข้าถึงง่าย
* **การอธิบายรูปภาพด้วย AI**: อธิบายข้อความรูปภาพหรือสติกเกอร์ที่โฟกัสอยู่ด้วยบริการ AI ที่ตั้งค่าได้ และถามต่อได้ในหน้าต่างที่เข้าถึงง่าย
* **การตอบกลับสถานะ**: ประกาศสถานะไมโครโฟน/กล้องระหว่างการโทร พร้อมเล่นเสียงสั้นเมื่อส่งข้อความสำเร็จจริง

## คำแนะนำการใช้งาน (Usage Tips)

* **การสร้างการเชื่อมต่อ**: ก่อนจะใช้ส่วนเสริมนี้ส่งข้อความหาใครเป็นครั้งแรก แนะนำให้ส่งข้อความหาคนนั้นผ่านโทรศัพท์มือถือหรือ LINE บน Chrome ก่อนอย่างน้อยหนึ่งข้อความ เนื่องจากประวัติการแชทจะช่วยให้ส่วนเสริมค้นหาตำแหน่งขององค์ประกอบต่าง ๆ ได้แม่นยำยิ่งขึ้น
* **การส่งข้อความ**:
    1. ค้นหาชื่อเพื่อน โดยพยายามใช้คำค้นหาที่แสดงผลลัพธ์เพียงรายการเดียวเพื่อป้องกันความผิดพลาด
    2. กด `Enter` ที่ห้องแชทเพื่อเปิด โฟกัสจะย้ายไปที่รายการข้อความ จากนั้นกด `Tab` เพื่อไปยังช่องพิมพ์ข้อความ (Edit field)
    3. พิมพ์ข้อความแล้วกด `Enter` เพื่อส่ง
* **การโทรออก**:
    ขณะนี้ไม่สามารถกดโทรออกได้โดยตรงจากแท็บแชทด้วยส่วนเสริมนี้ โปรดทำตามขั้นตอนต่อไปนี้:
    1. กด `Control+1` เพื่อสลับไปยังแท็บเพื่อน
    2. ค้นหาชื่อเพื่อน เลือกเพื่อน และเปิดห้องแชท
    3. กด `NVDA+Windows+C` เพื่อโทรด้วยเสียง หรือกด `NVDA+Windows+V` เพื่อโทรด้วยวิดีโอ
* **การอธิบายรูปภาพ**:
    1. ย้ายโฟกัสไปยังข้อความรูปภาพหรือสติกเกอร์
    2. กด `NVDA+Windows+I`
    3. อ่านผลลัพธ์ในหน้าต่างคำอธิบายรูปภาพ หรือพิมพ์คำถามต่อเนื่องแล้วกด `Ctrl+Enter`
* **การตรวจสอบ**: ควรตรวจสอบประวัติการแชทและชื่อผู้รับให้แน่ใจทุกครั้งก่อนจะส่งข้อความหรือกดโทรออก

### เอฟเฟกต์เสียง

* **เสียงเมื่อส่งข้อความ**: เมื่อกด `Enter` ในช่องข้อความและ LINE ส่งข้อความสำเร็จจริง ส่วนเสริมจะเล่นเสียงสั้น ๆ หาก `Enter` ใช้เพียงยืนยันการพิมพ์ของ IME จะไม่มีเสียง

## การอ่านและคัดลอกข้อความ

* **การอ่านข้อความ**: เมื่อใช้ LINE 26.6.0.4004 หรือใหม่กว่า และเลื่อนดูรายการข้อความด้วยปุ่มลูกศร NVDA จะอ่านแต่ละข้อความได้เอง รวมถึงชื่อผู้ส่ง ข้อความต้นฉบับที่ถูกตอบกลับ เวลา และจำนวนผู้อ่าน ส่วนเสริมจะไม่คลิกขวาที่ข้อความหรือใช้ OCR เพื่ออ่านอีกต่อไป และจะไม่แตะต้องคลิปบอร์ดของคุณ
* **การคัดลอกข้อความ**: กด `Control+C` ในรายการข้อความ ส่วนเสริมจะเลือก "คัดลอก" จากเมนูคลิกขวาของ LINE เองสำหรับข้อความที่โฟกัสอยู่ หากเมนูไม่มีรายการ "คัดลอก" ส่วนเสริมจะแจ้งให้ทราบ

## โปรแกรมอ่านข้อความและเมนูคลิกขวา

* **โปรแกรมอ่านข้อความ (`NVDA+Windows+J`)**: ส่วนเสริมจะเปิดเมนู "ตัวเลือกเพิ่มเติม" ของห้องแชท เลือก "บันทึกแชท" โดยอัตโนมัติ แยกวิเคราะห์ข้อความที่ส่งออก แล้วเปิดหน้าต่างอ่านที่เข้าถึงได้ง่าย
* **การนำทางในโปรแกรมอ่านข้อความ**: ใช้ `UpArrow` / `DownArrow` เพื่อเลื่อนทีละรายการ, `PageUp` / `PageDown` เพื่อข้ามครั้งละ 10 รายการ, `Ctrl+Home` / `Ctrl+End` เพื่อไปยังรายการแรก/รายการสุดท้าย และกด `Escape` เพื่อปิด หน้าต่างจะคงบรรทัดแบ่งวันที่ไว้และประกาศตำแหน่งปัจจุบัน
* **เมนูคลิกขวาข้อความ (`Applications` / `Shift+F10`)**: ในรายการข้อความ ปุ่มเหล่านี้จะเปิดเมนูคลิกขวาของ LINE เองสำหรับข้อความที่โฟกัสอยู่ (ตอบกลับ คัดลอก แชร์ เรียกคืน แปล "แปลงเป็นข้อความ" และอื่น ๆ) และ NVDA อ่านได้โดยตรง ใช้ `ลูกศรขึ้น` / `ลูกศรลง` เพื่อเลื่อน `Enter` เพื่อเลือก และ `Escape` เพื่อปิด ส่วนเสริมไม่แทนที่ด้วยเมนูเสมือนที่ใช้ OCR อีกต่อไป
* **คีย์ลัดสำหรับข้อความ**: `NVDA+Windows+R` (ตอบกลับ), `NVDA+Windows+K` (บันทึกเป็น), `NVDA+Windows+Delete` (เรียกคืน) และ `Control+C` (คัดลอก) จะเปิดเมนูเดียวกันนี้และเลือกรายการให้คุณ จึงใช้ได้เฉพาะเมื่อเมนูของ LINE มีรายการนั้น
* **การยืนยันการเรียกคืน**: หลังเลือกเรียกคืน (จากเมนูหรือด้วย `NVDA+Windows+Delete`) LINE จะแสดงกล่องโต้ตอบยืนยันของตัวเองและ NVDA อ่านได้โดยตรง กด `Tab` เพื่อฟังคำถามและไปยังปุ่ม **เรียกคืน** แล้วกด `Space` หรือ `Enter` ส่วนเสริมไม่เปิดกล่องโต้ตอบของตัวเองอีกต่อไป
* **ประกาศการแปลงรูปภาพเป็นข้อความ**: ประกาศอัปโหลดรูปภาพครั้งแรกของ "แปลงเป็นข้อความ" ก็ปล่อยให้กล่องโต้ตอบของ LINE เองจัดการเช่นกัน

## การอธิบายรูปภาพด้วย AI

* **คีย์ลัด (`NVDA+Windows+I`)**: จับภาพข้อความรูปภาพหรือสติกเกอร์ที่โฟกัสอยู่ และส่งไปยังบริการอธิบายรูปภาพที่ตั้งค่าไว้
* **หน้าต่างโต้ตอบ**: คำอธิบายแรกจะเปิดในหน้าต่างที่ปรับขนาดได้ พร้อมประวัติการสนทนาแบบอ่านอย่างเดียว คุณสามารถถามต่อเกี่ยวกับรูปเดิมในช่องป้อนข้อความ แล้วกด `Ctrl+Enter` เพื่อส่ง
* **การตั้งค่า**: เปิด "เมนู NVDA -> การตั้งค่า -> LINE Desktop" เพื่อเลือกบริการอธิบายรูปภาพ API Key โมเดล และพรอมต์ หากเว้น API Key หรือพรอมต์ว่างไว้ ระบบจะใช้ค่าเริ่มต้น
* **ข้อควรทราบด้านความเป็นส่วนตัว**: การอธิบายรูปภาพจะส่งภาพข้อความที่จับได้ไปยังบริการ AI คลาวด์ที่เลือก เมื่อใช้บริการใดเป็นครั้งแรก จะมีกล่องขอความยินยอมที่ระบุชื่อบริการนั้นปรากฏขึ้น และจะไม่มีการอัปโหลดใด ๆ จนกว่าคุณจะยินยอม ระบบจะถามทั้งกรณีที่ใช้คีย์ส่วนกลางที่มากับส่วนเสริมและกรณีที่ใช้ API Key ของคุณเอง เพราะสิ่งที่ต้องยืนยันคือ "บริษัทใดจะได้รับภาพหน้าจอของคุณ" ความยินยอมจะถูกจดจำแยกตามบริการ หากเปลี่ยนไปใช้บริการอื่นจะถามอีกครั้ง โปรดเลือกผู้ให้บริการและพรอมต์ให้เหมาะกับเนื้อหาที่ต้องการอธิบาย

## คีย์ลัด (Keyboard Shortcuts)

> [!NOTE]
> ในคอลัมน์ "หมวดหมู่" คำว่า "ส่วนเสริม" หมายถึงคีย์ลัดที่ส่วนเสริมนี้จัดเตรียมให้ และ "LINE" หมายถึงคีย์ลัดที่มาพร้อมกับ LINE Desktop

> [!TIP]
> คุณสามารถปรับแต่งคีย์ลัดเหล่านี้ได้ผ่าน "เมนู NVDA → การตั้งค่า → ท่าทางการป้อนข้อมูล"

### การโทรและสายเรียกเข้า

| คีย์ลัด | หมวดหมู่ | คำสั่ง |
|---|---|---|
| **NVDA+Windows+C** | ส่วนเสริม | เริ่มการโทรด้วยเสียง (Voice Call) |
| **NVDA+Windows+V** | ส่วนเสริม | เริ่มการโทรด้วยวิดีโอ (Video Call) |
| **NVDA+Windows+A** | ส่วนเสริม | รับสายเรียกเข้า |
| **NVDA+Windows+D** | ส่วนเสริม | ปฏิเสธสายเรียกเข้า |
| **NVDA+Windows+S** | ส่วนเสริม | ตรวจสอบข้อมูลผู้โทร |
| **NVDA+Windows+F** | ส่วนเสริม | ไปยังหน้าต่างการโทร |
| **Ctrl+Shift+A** | LINE | เปิด/ปิดไมโครโฟน; ระหว่างการโทร ส่วนเสริมจะประกาศสถานะใหม่ |
| **Ctrl+Shift+V** | LINE | เปิด/ปิดกล้อง; ระหว่างการโทร ส่วนเสริมจะประกาศสถานะใหม่ |

### การจัดการข้อความ

| คีย์ลัด | หมวดหมู่ | คำสั่ง |
|---|---|---|
| **Control+C** | ส่วนเสริม | คัดลอกข้อความปัจจุบัน (ใช้ในรายการข้อความ; ในช่องแก้ไขจะเป็นการคัดลอกปกติ) |
| **NVDA+Windows+R** | ส่วนเสริม | ตอบกลับข้อความปัจจุบัน |
| **NVDA+Windows+Delete** | ส่วนเสริม | เรียกคืนข้อความ (ยกเลิกการส่ง) จากนั้น LINE จะแสดงกล่องโต้ตอบยืนยันของตัวเอง |
| **NVDA+Windows+T** | ส่วนเสริม | อ่านชื่อห้องแชทปัจจุบัน |
| **NVDA+Windows+K** | ส่วนเสริม | เปิดกล่องโต้ตอบบันทึกเป็น (ไฟล์สามารถดาวน์โหลดได้เพียง 7 วันหลังอัปโหลด) |
| **NVDA+Windows+I** | ส่วนเสริม | อธิบายข้อความรูปภาพหรือสติกเกอร์ปัจจุบันด้วยบริการ AI ที่ตั้งค่าไว้ |
| **Applications / Shift+F10** | LINE | เปิดเมนูคลิกขวาของ LINE สำหรับข้อความปัจจุบัน |
